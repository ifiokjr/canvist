# Quick start: React Native and Lynx

Use this page to see what's planned for React Native and Lynx and what you can build with canvist today.

**Status: coming soon.** `@canvist/react-native` and `@canvist/lynx` aren't available yet. They will wrap the native iOS and Android editors, not a WebView, so typing feels native and your app keeps one JavaScript API for commands.

## What you can do today

- **Use the engine in JavaScript.** [`@canvist/headless`](./server-typescript.md) runs in any runtime with WebAssembly. Use it on your server to prepare and convert content.
- **Learn the model now.** These packages will use the same [extensions](../concepts/extensions.md) and [typed commands](../concepts/commands.md) as every other platform.

Watch [the releases](https://github.com/canvist/canvist/releases) to hear when they ship.
