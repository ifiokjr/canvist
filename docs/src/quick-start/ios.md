# Quick start: iOS

Use this page to see what's planned for iOS and what you can build with canvist today.

**Status: coming soon.** The native iOS editor isn't available yet. It will be a `CanvistView` in a Swift package, built on `UITextInput`, so autocorrect, dictation, and the selection loupe work as they do in native text views. It will draw with CoreText and CoreGraphics, and follow Dynamic Type.

## What you can do today

- **Build with Flutter.** [`canvist_flutter`](./flutter.md) runs the full engine on iOS today.
- **Process content on your server.** Use the [Rust](./server-rust.md), [TypeScript](./server-typescript.md), or [Dart](./server-dart.md) packages.

Watch [the releases](https://github.com/canvist/canvist/releases) to hear when it ships.
