# canvist-android

The Android library for canvist, published as `io.github.ifiokjr:canvist-android`. It wraps the Rust core through [`canvist_ffi`](../../crates/canvist_ffi), with Kotlin bindings generated by UniFFI.

**Status: coming soon.** Today the library proves the build, binding, and emulator test pipeline end to end, with a placeholder handle that holds plain text. The native editor arrives behind the same API. See the [Android quick start](../../docs/src/quick-start/android.md).

<details>
<summary><strong>Development</strong></summary>

```sh
./build.sh   # cross-compile the Rust core with cargo-ndk and generate the Kotlin bindings
./test.sh    # the library's and the sample app's instrumented tests on a device or emulator
```

</details>
