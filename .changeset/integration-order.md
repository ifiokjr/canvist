# Order the integrations by ecosystem popularity

The docs sidebar, the platform tables, the agent guide, and `/llms.txt` now list integrations by expected usage: the TypeScript ecosystem first (React, React Native, Vue, web, server-side rendering, the TypeScript server, and the design canvas), then Flutter with the Dart server, iOS, Android, desktop with the Rust server, and Lynx last.
