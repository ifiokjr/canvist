# canvist runs in React Native and Lynx apps

## User impact

Apps built with React Native or Lynx can now add canvist's editor. It is the same native editor as on iOS and Android, so typing, autocorrect, dictation, selection, and screen readers work as people expect, not like a web page squeezed into an app. The platforms section of the website shows both as available.
