# Add the /changelog page for app releases

`/changelog` renders the `changelog` collection (the user release stream monochange writes into `website/src/content/changelog/`), newest version first, with a linkable heading per release and an empty state until the first app release. The footer links to it, and the page joins the end-to-end sweeps (navigation, responsiveness and accessibility in both themes).
